# 🎮 Oyun Projelerim

Bu projede HTML, CSS ve JavaScript kullanılarak geliştirilmiş iki oyun bulunmaktadır.

## 1. Piramitten Kaçış
Piramit içerisinde geçen, engellerden ve tuzaklardan kaçarak bölümleri tamamlamaya dayalı 2D parkur oyunudur.

## 2. Hızlı Kelimeler
Ekranda hızlıca gösterilen kelimeleri akılda tutarak VAR/YOK sorularını doğru cevaplamaya dayalı hafıza ve refleks oyunudur.

## Kullanılan Teknolojiler
- HTML
- CSS
- JavaScript

## Nasıl Oynanır?
Oyunların HTML dosyaları tarayıcıda açılarak oynanabilir.
